# ❄️ Зимние Пустыни
*Версия: 0.0.3 | Minecraft: 1.21.8 | Загрузчик: NeoForge*

> 🧭 *Ранний доступ*

**Зимние Пустыни** — это мод для Minecraft, добавляющий суровые полярные ландшафты в ваш мир. В текущей версии реализован **биом Антарктиды**, новые блоки и инструменты для выживания в экстремальном холоде.

> [!IMPORTANT]
> Это ранняя версия мода. Контент будет расширяться: в планах — Арктика, Адарктика, мобы, структуры и Россия как новый регион мира.

---

## ✨ Что есть в версии 0.0.3

### 🌍 Биом
| Биом | Описание |
|------|----------|
| **Антарктида** ❄️ | Снежные равнины, ледяные пики, экстремальный холод. Идеально для исследований и выживания. |

### 🧱 Новые блоки
| Блок | Особенности |
|------|-------------|
| Ледяной кирпич | Декоративный строительный блок, устойчивый к таянию |
| Твёрдый снег | Не проваливает игрока, подходит для дорог |
| Кристальное бревно | Уникальная текстура, слабо светится в темноте |
| Кристальная листва | Декоративная листва с частицами |
| Кристалл | Редкий ресурс для крафта и декора |

### 🪓 Новые инструменты
| Инструмент | Особенность |
|------------|-------------|
| Холодный топор | +урон, замедляет цель при ударе |
| Холодная кирка | Быстрее добывает лёд и снежные блоки |

> 🔨 Оба инструмента имеют уникальные рецепты крафта — смотрите в JEI/REI!
