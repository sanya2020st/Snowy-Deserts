# ❄️ Snowy Deserts
*Version: 0.0.3 | Minecraft: 1.21.8 | Loader: NeoForge*

> 🧭 *Early Development Release*

**Snowy Deserts** is a Minecraft mod that adds harsh polar landscapes to your world. The current version features the **Antarctica biome**, new blocks, and tools to help you survive in extreme cold.

> [!IMPORTANT]
> This is an early version of the mod. Content will be expanded: planned features include Arctic, Adarctic, mobs, structures, and Russia as a new world region.

---

## ✨ What's in Version 0.0.3

### 🌍 Biome
| Biome | Description |
|-------|-------------|
| **Antarctica** ❄️ | Snowy plains, ice peaks, extreme cold. Perfect for exploration and survival. |

### 🧱 New Blocks
| Block | Features |
|-------|----------|
| Ice Brick | Decorative building block, resistant to melting |
| Hard Snow | Doesn't cause player to sink, suitable for roads |
| Crystal Log | Unique texture, glows faintly in darkness |
| Crystal Leaves | Decorative leaves with particle effects |
| Crystal | Rare resource for crafting and decoration |

### 🪓 New Tools
| Tool | Special Ability |
|------|-----------------|
| Cold Axe | +damage, slows target on hit |
| Cold Pickaxe | Mines ice and snow blocks faster |

> 🔨 Both tools have unique crafting recipes — check JEI/REI!

## 🗺️ Planned Features
🔜 Arctic — white forest, icebergs, polar mobs

🔜 Adarctic — fantasy biome with crystal storms

🔜 Russia — new world region with climate zones

🔜 Mobs: penguins, seals, polar bears, walruses, blue whales

🔜 Structures: radio stations, traveler houses, icebreaker installations

🔜 Weather system: crystal storm that crystallizes players

🔜 Advancements and cold damage mechanics
